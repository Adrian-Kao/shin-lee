【名稱】Software Defined Network Controller with Flow Caching

【摘要】
An SDN controller architecture employing flow caching to reduce switch-controller round-trip time for repeated flows.

【說明書節錄】
Background: SDN controllers introduce RTT overhead.
Description: Cache reduces lookup time.


【申請專利範圍】
請求項 1：1. An SDN controller comprising: a flow table receiver; a flow rule generator; and a flow cache configured to store recently generated rules for repeated lookup.
